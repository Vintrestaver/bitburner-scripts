## 核心数据结构

```js
// daemon.js 的脚本描述符（三类清单共用）
{ name: "stockmaster.js",        // 脚本路径
  shouldRun: () => reqRam(64),   // 启动条件谓词
  args: [...] | () => [...],     // 静态/动态参数
  minRamReq: 20.2,               // 最低 RAM 门槛
  shouldTail: true,              // 是否弹 tail 窗
  runOptions: { temporary },     // ns.run 选项
  ignoreReservedRam: true,       // 计算可用 RAM 时是否忽略 reserve
  interval: 30000 }              // 仅周期任务：轮询间隔

// Remote worker 参数协议（ns.args 位置参数）
[target, start_time, duration, description, manipulateStock, silentMisfires, loopingMode]
```
