## 1. 安装与更新

**首次安装**（在游戏终端）：
```
nano git-pull.js   # 粘贴仓库中 git-pull.js 的内容并保存
run git-pull.js    # 从 GitHub 下载全部脚本（含 Remote/ 与 Tasks/）
```

`git-pull.js` 工作机制：GitHub API 递归列出仓库文件（注意每小时 60 次限额，失败时回退到本地 `ns.ls`）→ `ns.wget` 逐个下载 → `rewriteFileForSubfolder` 改写 import 路径以下载到子目录 → 收尾运行 `cleanup.js` 清 `/Temp/`。

**使用自己的 fork**：`run git-pull.js --github <用户名> --repository bitburner-scripts`，或设别名永久生效。

## 2. 启动方式

| 场景 | 命令 |
|---|---|
| 全自动（推荐） | `run autopilot.js` |
| 仅黑客自动化 | `run daemon.js` |
| 快速停全部 | `home; kill autopilot.js; kill daemon.js; run kill-all-scripts.js` |
| 单独体验某模块 | `run casino.js` / `run stockmaster.js --tail` 等 |

建议别名（README 推荐）：`alias start="run autopilot.js"`、`alias sscan="home; run scan.js"`、`alias do="run run-command.js"`、`alias liquidate="home; run stockmaster.js --liquidate; run spend-hacknet-hashes.js --liquidate;"`、`alias ascend="run ascend.js --install-augmentations"` 等。

> **注意**：daemon/autopilot 只拉起"未在运行"的脚本（按文件名判断）。想自定义参数，先手动以目标参数启动，再启动编排器。

## 3. 参数系统（三级优先级）

每个脚本顶部定义 `argsSchema`（`[['flag-name', 默认值, 说明], ...]`），由 `helpers.js` 的 `getConfiguration`（[L814](../helpers.js)）统一解析：

```
命令行参数  >  <script>.js.config.txt  >  argsSchema 默认值
```

- **`--help`**：任何脚本可用，打印全部参数、默认值与说明
- **Tab 补全**：`run daemon.js --` + `<Tab>` 弹出参数列表；脚本可导出 `autocomplete(data, args)` 自定义
- **config.txt 持久化**：如 `daemon.js.config.txt`，内容为 JSON 字典或二元组数组：
  ```json
  { "looping-mode": true, "stock-manipulation": true, "queue-delay": 10 }
  ```
  这样自定义配置不会被 `git-pull.js` 更新覆盖

## 4. 常用运行处方

| 目的 | 命令 |
|---|---|
| 刷 hack XP | `run daemon.js -vx --tail --no-share` |
| 末期高性能调度 | `run daemon.js --looping-mode --recovery-thread-padding 30 --cycle-timing-delay 2000 --queue-delay 10 --stock-manipulation-focus --tail --silent-misfires --initial-max-targets 64` |
| 重置前变现 | `run stockmaster.js --liquidate; run spend-hacknet-hashes.js --liquidate` |
| 查看/购买增强 | `run faction-manager.js` / `run faction-manager.js --purchase` |
| 全自动重置 | `run ascend.js --install-augmentations`（`--prioritize-home-ram` 可优先 RAM） |
| 刷派系邀请 | `run work-for-factions.js --fast-crimes-only --get-invited-to-every-faction --prioritize-invites --no-coding-contracts` |
| 大买服务器 | `run host-manager.js --run-continuously --reserve-percent 0 --min-ram-exponent 19 --utilization-trigger 0 --tail` |

## 5. 调试工具

- `run run-command.js ns.getPlayer()` —— 终端直接执行 ns 代码（配合别名 `do`）
- `run grep.js [文件] <文本>` —— 游戏内搜索脚本内容
- `run dump-ns-namespace.js stock` —— dump 某个 NS 命名空间的成员
- `run scan.js` —— 全网状态视图
- `run dev-console.js` —— 打开游戏 Dev 页面

## 6. 维护与 CI

- **CI**（`.github/workflows/inclusive_language.yml`）：push/PR 到 `main` 时运行 [woke](https://github.com/get-woke/woke) 包容性语言检查，无构建/测试流程（游戏内脚本无法离线运行）
